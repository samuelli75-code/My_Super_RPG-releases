# My Super RPG

A Minecraft Bedrock add-on that turns the game into a full RPG: custom HP / MP, five classes with skill trees, 32 spells, downed-and-rescue, money and a pawnshop, a story saga in Happy Village and Contentment Town, and a bounty board.

Made by Samuel, Josiah & Elizabeth.

## Download

Get the latest `.mcaddon` from [Releases](../../releases/latest).

1. Download `My_Super_RPG.<version>.mcaddon` (if it saves as `.zip`, rename it back to `.mcaddon`).
2. Open the file and Minecraft imports the behavior pack and resource pack.
3. When creating a world, enable My Super RPG under Behavior Packs (the resource pack comes with it).
